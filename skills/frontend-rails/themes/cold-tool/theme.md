# cold-tool

A precise tool. One sans family (IBM Plex Sans) with a mono for code, cool greys, blue accent, small radius, compact 14px base text.

**Good for:** developer tools, SaaS apps, settings pages, internal tools, product landing pages for technical buyers.
**Not great for:** food, fashion, anything that should feel warm.

**Make it work:**
- Use borders and `--surface` vs `--bg` to separate areas. Shadows only for menus and dialogs.
- Show the product: a screenshot, a code sample, a real table.
- Keep the accent for primary actions, links, and selected states.
- Status colors only for status (badges, alerts), never decoration.

**Feels like:** a well-made developer dashboard or CLI tool's site.
