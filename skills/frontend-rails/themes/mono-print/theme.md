# mono-print

Swiss print. Black and white, one red spot color, square corners, heavy Archivo headlines, Space Mono for small labels. Borders are solid black.

**Good for:** portfolios, agencies, events, manifestos, bold reports.
**Not great for:** soft consumer products, dense apps.

**Make it work:**
- Use a strict grid and big type contrast (huge headline, small body).
- Separate sections with solid rules, not boxes or shadows.
- Use red for one thing per screen.
- No shadows, no rounded corners, no gradients.

**Feels like:** a Swiss poster or a design studio's site.
