# dense-ledger

High-density data. Geist and Geist Mono, 13px base text, tight spacing scale (2–48px), neutral greys, teal accent. Controls are 32px on desktop and 44px on phones.

**Good for:** tables, finance, admin panels, ops dashboards, anything with many numbers.
**Not great for:** marketing pages, long reading.

**Make it work:**
- Fit a lot on screen, but keep alignment strict: numbers right-aligned with `class="num"`.
- Group with whitespace and thin borders, not cards inside cards.
- Put filters and actions in one toolbar row above the table.
- Every view needs loading, empty and error states (see `archetypes/app.md`).

**Feels like:** a calm accounting or monitoring tool.
