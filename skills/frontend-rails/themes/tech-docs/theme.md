# tech-docs

Clear documentation. Hanken Grotesk for everything, JetBrains Mono for code, white page, petrol-blue links, comfortable 1.7 line height.

**Good for:** documentation, API references, technical write-ups, changelogs, how-to reports.
**Not great for:** brand-heavy marketing pages.

**Make it work:**
- Body text in `.prose` (max ~72ch).
- Side navigation or a table of contents for long pages.
- Code in `<pre>` blocks; inline code in `<code>`.
- Use `.alert-info` / `.alert-warning` for notes and warnings.

**Feels like:** a well-kept docs site for a developer product.
