# editorial-ink

A printed magazine page. Big serif headlines (Newsreader), plain sans body text (Public Sans), warm paper background, one ink-red accent.

**Good for:** long reads, reports, studios, publications, landing pages for thoughtful products.
**Not great for:** dense dashboards, playful consumer apps.

**Make it work:**
- Let headlines be large and left-aligned. Give them room.
- Use thin rules (`border-top: 1px solid var(--border)`) to separate sections instead of boxes.
- Use the accent rarely: links, one button, a pull quote mark.
- Pictures: full-width photos or none.

**Feels like:** a well-set newspaper feature or a literary magazine site.
