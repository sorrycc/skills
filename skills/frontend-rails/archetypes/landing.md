# Landing page

A landing page has one job: get the visitor to take one action. Everything on it should help that.

## First screen

- One clear focus: the headline, plus either a product image or nothing.
- Headline says what it is and who it's for, in plain words. Under ~10 words.
- One primary button. A second, quieter link is fine.

## Pick a section order

Choose the one that fits the product. Don't use all of them.

1. **Show the product**: hero → big product screenshot → 3–4 features as short rows (image + text, alternating) → pricing → final call to action
2. **Explain a process**: hero → numbered steps (how it works) → what you get → FAQ → call to action
3. **Proof first**: hero → customer quote or numbers → features → case study → call to action
4. **Single story**: hero → one long section of prose and images, like an article → call to action
5. **Compare**: hero → table comparing you vs the usual way → details → pricing
6. **Local business**: hero with photo → what we offer (menu / services list) → hours and location → contact

## Tips

- Vary the layout between sections: a split, then a full-width image, then a list. Not the same card grid over and over.
- Specific beats generic: "ships Wednesday" beats "fast delivery".
- Use real images or a plain `--surface-2` box labeled with what will go there. No fake stock-art shapes.
- Not every heading needs a subtitle. See `copy.md`.
- People came to use the site, not to watch it. No sections fading in on scroll, no scroll hijacking, no custom cursor, no carousel. The gate fails the first three.
- Anything that navigates is a real link with an `href`, so it opens in a new tab.
